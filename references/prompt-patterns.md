# 完整单页提示词结构

用于编写可直接交给图像工具的每页说明。实际保存时把所有字段写成具体内容，不留下占位符，不要求图像模型访问其他提示词。

```text
任务：生成一张用于电商详情页的独立图片。
页码及目的：[这一页解决的具体信息任务]
画幅：[用户要求的比例；精确像素仅在工具支持并能验证时承诺]

参考输入与分工：
- 商品参考：[真实商品素材，对应形状、颜色、结构和可辨认标识]
- 视觉参考：[只继承配色、构图、字体气质和光线]
- Logo：[存在时使用；没有则明确不添加]
- 待编辑图：[仅修改任务填写，说明只改变什么]

商品主体与不变项：[完整、具体地重复商品外观约束]
本页画面：[景别、角度、构图、场景；只呈现有依据的部件和使用方式]
共同视觉规则：[具体配色、背景、光线、留白、文字层级和图形效果]
本页布局：[商品占比、标题/正文位置、对齐关系及安全边距]
图片中精确出现的文字：
- 标题：「已核实或不涉及未知事实的实际文案」
- 副标题：「实际文案；不需要则省略」
- 要点/参数：「逐项列出实际内容；不得自动补值」
文字要求：[语言、字体气质、层级、清楚可读；只出现列明的文字]
排除项：[当前页面确实不需要的内容；不与前文要求矛盾]
```

参考图片必须通过工具实际传入；在文字里写路径或说「参见产品图」不等于传入图片。多图输入在提示词中明确对应顺序和角色。

## 示例：只有文字的马克杯

用户信息：哑光浅绿色陶瓷马克杯，圆柱杯身、C 形把手，无品牌，要求六张米白极简详情图。

可使用的内容：用户描述的颜色、表面质感、形状、把手以及合理的桌面场景。
不能自行添加：容量、尺寸、重量、耐高温数值、食品认证、可进微波炉/洗碗机、隔热性能和保修政策。

可按「主视觉、整体侧面、杯口近景、把手细节、桌面场景、整体收尾」组织六页。先生成与文字相符的外观基准，后续引用它。无需因为缺少参数而强制停下来。

## 示例：真实商品图加不同品类的风格图

用户上传运动鞋照片和一张香水广告作为风格参考。外形、鞋底结构、鞋带、配色来自运动鞋照片；香水广告仅提供暗色背景、轮廓光和标题布局。不能生成香水瓶、照抄香水品牌或把鞋改造成参考图的材质。

## 提示词自检

- 不同时要求「纯平无阴影」和「强立体投影」，也不在允许渐变的页面排除所有渐变。
- 图片细节支持的是外观展示；无实物/结构依据时，不做看似真实的内部剖面或性能实验图。
- 没有明确需要时，避免多个语言段落、大片小字以及每页重复的购买按钮。
- 真实售后承诺、价格与折扣只使用用户给出的当前信息。
