# 把风格偏好变成可执行的视觉规则

用户的具体要求优先，其次品牌资料/参考图，最后才是默认风格。以下是起点，不是封闭菜单；可混合或完全自定义。

| 用户可能说 | 可落地的方向 |
|---|---|
| 极简、高级、旗舰店 | 少量色彩、强主次、克制光线、足够留白，突出商品本体 |
| 奶油、治愈、自然 | 暖中性色、柔和日光、低对比背景；保留商品真实颜色 |
| 科技、黑金、未来感 | 深色底、明确轮廓光、少量金属色点缀、清楚的信息分区 |
| 杂志、编辑感、大字 | 鲜明字体层级、网格排版、近远景变化；装饰字不压住商品 |
| 活泼、彩色、年轻 | 明亮底色、圆润信息块、短文案；保持清楚的阅读顺序 |
| 东方、国风、雅致 | 适量纸感/自然材质、克制传统元素、疏密变化；不擅自加印章品牌 |
| 专业、参数清楚、少装饰 | 简洁网格、对比明确的文字、真实规格表、局部实拍式展示 |

确定风格时只记录影响整套输出的内容：

```text
视觉方向：
主色 / 辅色 / 强调色（可指定 HEX）：
背景与质感：
光线与对比：
标题 / 正文字体气质：
标题、正文、注释的层级：
边距 / 留白 / 对齐：
图标 / 信息卡效果：
文案语言 / 密度：
Logo（如有）的固定位置及相对大小：
保持的产品特征：
允许变化的场景、镜头与构图：
```

字体名称是生成指导，不代表最终获得可编辑字体文件或保证字形完全一致。若用户要求精确字体或精确排版，说明图像生成的实际限制，并以检查结果判断是否达标。

风格参考图只用于读出视觉规则：不要照搬其商品、人物身份、商标、数据或文案。可以概括为「暖白背景、柔光、居中主体、左对齐细字」等可复用特征。

单页改变布局可以沿用全套色板和文字层级。若用户只改某一张的风格，尊重该范围，同时说明该页将与其余页面有差异，不擅自重做全套。
